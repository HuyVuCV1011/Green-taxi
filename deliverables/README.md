# Deliverables

- `reports/`: DOCX/PDF bản nộp.
- `slides/`: PPTX bản trình bày.
- `spreadsheets/`: XLSX theo dõi hoặc kết quả cần bàn giao.
- `demo/`: kịch bản quay, audit report, checklist, phụ đề và manifest cho video
  demo. Video dashboard-only mới nhất nằm ở
  `demo/dashboard_only_20260713/green_taxi_dashboard_demo_20260713.mp4` trong
  workspace local; file MP4 không được commit theo rule của project.

Các binary lớn nên dùng Git LFS nếu thực sự cần theo dõi lịch sử. Bản nháp cũ
được đưa vào `archive/`, không đặt lẫn với bản nộp hiện hành.
